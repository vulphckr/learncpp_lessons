Il programma seguente: 
```cpp
#include <iostream>

int main() {
	// get a value from the user
	std::cout << "Enter an integer: ";
	int num{};
	std::cin >> num;

	// print the value doubled
	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}
```
Si compone di due parti: una dove viene richiesto un valore in input dall'utente, l'altra dove viene stampato il valore raddoppiato.
Supponiamo di suddividere "fisicamente" il programma in due funzioni distinte: nel `main()` mettiamo la stampa del valore raddoppiato, mentre nella funzione che scriviamo noi vogliamo richiedere l'inserimento di un numero da parte dell'utente.

Una possibile soluzione potrebbe essere:
```cpp
#include <iostream>

void getValueFromUser() { // Funzione che richiede input utente
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;
}

int main() {
	getValueFromUser(); // Ask user for input

	int num{};

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}
```
Seppur sintatticamente corretto, questo programma ***non funziona***, poiché il valore richiesto in input dall'utente viene ***perduto quando l'esecuzione di `getValueFromUser()` termina***. In pratica, il valore richiesto, non viene **salvato da nessuna parte**, pertanto il programma stamperà `0`. 
Ci manca qualcosa che permette a `getValueFromUser()` di **restituire il valore inserito in input alla funzione `main()`**, così che `main()` possa usarla.

### Return values
Quando scriviamo una ***user-defined function*** dobbiamo decidere se tale funzione dovrà **restituire un valore o meno**. Se decidiamo di si, sarà necessario specificare due cose riguardanti tale funzione:
- Il ***return type*** (*tipo di ritorno*) della funzione, ossia **il tipo di dato che la funzione restituirà**. Per esempio, se una funzione ha *return type* `int`, essa restituirà valori di tipo `int`. Una funzione che non restituisce nulla avrà tipo `void`; vedremo in seguito come queste si comportano.
- All'interno della funzione dovrà essere presente un ***return statement*** che indica il valore specifico che dovrà essere restituito al chiamante. Lo statement è formato dalla keyword `return`, seguita da una ***return expression***, ossia un'[[1.10 ~ Introduction to expressions#Expressions|espressione]], terminata da un punto e virgola `;`.
Quando una funzione viene eseguita e si arriva al *return statement*:
- La *return expression* viene valutata al fine di ottenere un valore;
- Tale valore viene **copiato al chiamante della funzione** - questa copia viene detta ***return value*** della funzione;
- La funzione termina, e l'esecuzione riprende dal chiamante.
L'operazione di copia del valore dato da una funzione chiamata è detto ***return by value***.
Ogni volta che una funzione avente tipo di ritorno viene richiamata, **verrà restituito un valore ogni volta**.
```cpp
#include <iostream>

int cinque() { // Semplice funzione che restituisce il valore 5.
	return 5;
}

int main() {
	std::cout << cinque() << '\n'; // Stampa 5
	std::cout << cinque() + 2 << '\n'; // Stampa 7

	cinque(); // La funzione viene richiamata ma il valore non viene usato - non fa niente.

	return 0;
}

/* 
Output:
	5
	7
*/
```

Funzioni che hanno un tipo di ritorno **devono restituire un valore**. Se per qualche motivo (mancanza di `return`, interruzione dell'esecuzione prima dell'istruzione di `return`...) tale valore non viene restituito, verrà restituito un ***[[1.6 ~ Uninitialized variables and undefined behavior#Uninitialized Variables|valore indefinito]]***.
### La funzione `main()`
La funzione `main()` è **una particolare funzione** che viene eseguita per prima dal sistema operativo nel momento in cui un programma viene eseguito. Quando avviamo un programma, il SO esegue una chiamata a `main()` che inizierà ad eseguire le istruzioni in maniera sequenziale. Alla fine, `main()` restituisce un valore di tipo `int`, solitamente `0`, e il programma termina.

Ci sono due principali **proprietà che devono essere rispettate nei confronti di `main()`**:
- `main()` deve avere tipo di ritorno `int`;
- Chiamate esplicite alla funzione `main()` sono bandite.
Al momento definiamo `main()` sotto tutte le altre funzioni utente, ma poi vedremo che non sarà sempre così.

Il valore di ritorno di `main()` prende il nome di ***status code*** e indica se l'esecuzione del programma è stata corretta o meno. Di base, uno *status code* `0` indica che l'esecuzione è terminata correttamente, mentre se è diverso da `0` significa che è c'è stato un qualche tipo di errore. Se non viene specificato un valore di ritorno della funzione `main()` essa restituirà implicitamente `0`, tuttavia è buona pratica esplicitare sempre questo valore. 

### Principio DRY e riuso delle funzioni
L'uso delle funzioni permette di non violare il principio ***Don't Repeat Yourself (DRY)***, ossia di non ripetere il codice ove non necessario. Per esempio:
```cpp
#include <iostream>

int main() {
	int x{};
	std::cout << "Enter an integer: ";
	std::cin >> x;

	int y{};
	std::cout << "Enter an integer: ";
	std::cin >> y;

	std::cout << x << " + " << y << " = " << x + y << '\n';

	return 0;
}
```
Questo codice viola il principio DRY, siccome viene eseguita la stessa richiesta due volte, rendendo il codice ridondante e dando la possibilità a errori sintattici di apparire nel codice.
Possiamo usare le funzioni e la loro capacità di riuso per rispettare il principio DRY:

```cpp
#include <iostream>

int getValueFromUser() {
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;

	return input;
}

int main() {
	// Definita la funzione, la usiamo due volte.
    int x{ getValueFromUser() };
    int y{ getValueFromUser() };

    std::cout << x << " + " << y << " = " << x + y << '\n';

    return 0;
}
```

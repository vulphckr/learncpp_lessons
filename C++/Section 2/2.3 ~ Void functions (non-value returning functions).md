Abbiamo visto che, alcune volte, utilizziamo come tipo di ritorno per le funzioni `void`, senza però averne spiegato il significato - obiettivo di questa lezione è spiegare il comportamento di una funzione che ha tipo di ritorno `void`.

### Void return values
**Le funzioni non sono obbligate a restituire un valore al chiamante**. Per comunicare al compilatore che la nostra funzione non restituisce un valore, si utilizza il ***return type `void`***:
```cpp
#include <iostream>

void saluta() { // Tipo di dato void
	std::cout << "Ciao!" << '\n';
	// Nessun valore di ritorno, nè una return expression. 
}

int main() {
	saluta(); // OK: la funzione non ha valore di ritorno
	
	return 0;
}
// Output: Ciao!
```
Funzioni che non restituiscono valori si dicono ***void-functions*** o ***non-value returning functions***. Le funzioni di tipo `void` ***non richiedono un return statement al loro termine*** e termineranno non appena giungeranno al termine delle istruzioni al loro interno. L'istruzione di `return` può essere comunque utilizzata in una funzione `void` ed essa terminerà l'esecuzione di tale funzione e restituirà il controllo al chiamante - non è però necessario specificarlo al termine poiché è ridondante.

Le **void functions** non possono essere usate in espressioni che richiedono dei valori, siccome esse non restituiscono un valore. 
```cpp
#include <iostream>

void saluta() { // Tipo di dato void
	std::cout << "Ciao!" << '\n';
	// Nessun valore di ritorno, nè una return expression. 
}

int main() {
	saluta(); // OK: la funzione non ha valore di ritorno
	
	std::cout << saluta() << '\n'; // Errore, saluta() non è un valore.
	
	return 0;
}
```

Inoltre, se proviamo a restituire un valore all'interno di una funzione `void`, si avrà errore di compilazione.

```cpp
void saluta() { // Tipo di dato void
	std::cout << "Ciao!" << '\n';
	
	return 5; // Errore di compilazione.
}
```

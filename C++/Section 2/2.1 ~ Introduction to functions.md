Abbiamo visto inizialmente che cosa sono, in breve, delle [[1.1 ~ Statements and structure of a program#Statements & Functions|funzioni]]. In questo capitolo ci preoccupiamo di darne una definizione più rigorosa e permetterne un uso migliore.

### Funzioni
Una ***funzione*** è una **sequenza *riusabile*** di *statements* che svolgono una specifica mansione.

Sappiamo già che ogni programma hanno **una funzione principale chiamata `main()`**, da cui l'esecuzione del programma stesso avrà inizio. Siccome i programmi diventano sempre più lunghi, inserire tutto nella funzione `main()` diventa *difficile da gestire*.
La maggior parte dei programmi utilizza un alto numero di funzioni. La libreria standard C++, `iostream`, contiene già delle ***funzioni pre-costruite*** al suo interno, tuttavia è normale che certe funzioni vengano scritte direttamente dall'utente che scrive il codice - tali funzioni si chiamano ***user-defined functions***.

Il funzionamento di una chiamata a funzione è esprimibile tramite il seguente esempio: supponiamo di star leggendo un libro, quando ci ricordiamo che dobbiamo fare una chiamata al telefono; allora mettiamo un segnalibro che indica dove siamo arrivati a leggere e andiamo a fare la chiamata. Finita la chiamata riprendiamo la lettura del libro dal segnalibro.

I programmi in C++ funzionano **in modo uguale**. Il nostro programma eseguirà *statements* sequenziali finchè non incontrerà una ***function call*** (*chiamata a funzione*); questa comunica alla CPU di interrompere l'esecuzione della funzione corrente e di eseguire un'altra funzione, e questo viene fatto mettendo un "segnalibro" allo stato attuale di esecuzione, eseguendo la funzione richiesta, e poi **tornare nel punto detto dal segnalibro e riprendere l'esecuzione**.
In particolare:
- Chi effettua la chiamata a funzione è il ***caller*** (*chiamante*);
- La funzione ***chiamata*** è detta ***callee***;

Definiamo ora la sintassi della dichiarazione di una funzione tramite un esempio:
```cpp
returnType functionName() { // Function Header
	// Function Body
}
```
Possiamo notare due parti distinte, l'***header*** e il ***body***; la prima comunica al compilatore l'esistenza di questa funzione ed alcune sue informazioni importanti, mentre la seconda determina cosa la funzione fa nell'effettivo. Nell'header troviamo:
- `returnType`, ossia il **tipo di dato che la funzione produce**, che vedremo in seguito;
- `functionName()`, ossia ***l'identificatore della funzione***.

Per effettuare una chiamata a funzione, basta richiamarla tramite ***il suo identificatore seguito da parentesi tonde `()`***.
```cpp
#include <iostream>

void printThis() { // Funzione che stampa "Ciao!"
	std::cout << "Ciao!" << '\n';
}

int main() {
	std::cout << "Prima di salutare..." << '\n';
	printThis(); // Chiamata a funzione
	std::cout << "Dopo aver salutato..." << '\n';
	
	return 0;
}
/*
Output:
	Prima di salutare...
	Ciao!
	Dopo aver salutato...
*/
```

Proprietà utile delle funzioni è che **una volta definite si possono richiamare più volte**.
```cpp
#include <iostream>

void printThis() { // Funzione che stampa "Ciao!"
	std::cout << "Ciao!" << '\n';
}

int main() {
	printThis(); // Chiamata a funzione
	printThis(); // Chiamata a funzione
	printThis(); // Chiamata a funzione
	
	return 0;
}

/*
Output:
	Ciao!
	Ciao!
	Ciao!
*/
```
Inoltre, è possibile **richiamare funzioni all'interno di altre funzioni**:
```cpp
#include <iostream>

void anotherPrint() {
	std::cout << "Di nuovo ciao!" << '\n';
}

void printThis() { // Funzione che stampa "Ciao!"
	std::cout << "Ciao!" << '\n';
	anotherPrint(); // Chiamata ad un'altra funzione dentro a una funzione
}

int main() {
	printThis(); // Chiamata a funzione
	
	return 0;
}

/*
Output:
	Ciao!
	Di nuovo ciao!
*/
```
Le funzioni **non possono essere dichiarate dentro altre funzioni**, ciascuna va dichiarata separatamente.

Nelle [[2.2 ~ Function return values (value-returning functions)#Return values|scorse lezioni]] abbiamo visto che le funzioni possono **restituire valori a chi le ha chiamate**, in modo da poter rendere i programmi modulabili. In particolare, abbiamo visto il seguente programma:
```cpp
#include <iostream>

void getValueFromUser() { // Funzione che richiede input utente
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;
}

int main() {
	int num{ getValueFromUser() }; // Ask user for input

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}
```
che richiede l'input utente in una funzione apposita `getValueFromUser()`. Supponiamo ora di voler inserire anche la stampa del valore in un'altra funzione specifica:
```cpp
#include <iostream>

int getValueFromUser() {
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;

	return input;
}

// Funziona che stampa il doppio di num
void printDouble() {
	std::cout << num << " doubled is: " << num * 2 << '\n';
}

int main() {
	int num { getValueFromUser() };

	printDouble();

	return 0;
}
```
Seppur sintatticamente corretta, questo programma ***non può essere compilato***, in quanto `printDouble()` non conosce l'identificatore `num`. Possiamo pertanto istanziare tale variabile all'interno della funzione stessa:
```cpp
void printDouble() {
	int num{};
	std::cout << num << " doubled is: " << num * 2 << '\n';
}
```
Questo risolve l'errore di compilazione, ma il programma ***non funzionerà***, restituendo che `0 doubled is: 0`. In pratica, ***`printDouble()` non ha modo di accedere al valore inserito dall'utente***. Abbiamo pertanto bisogno di un modo per comunicare tale valore alla funzione, così che `printDouble()` riesca ad utilizzarlo.

### Functions parameters and arguments
In molti casi sarà necessario ***passare delle informazioni alla funzione chiamata***, in modo che essa abbia dei dati iniziali con cui lavorare. Supponiamo di avere una funzione che deve sommare due numeri: essa avrà bisogno dei due numeri da sommare al fine di poter fornire un risultato. 
Il passaggio di questi valori iniziali viene fatto per mezzo dei ***function parameters***: questi sono **variabili posti nell'*header* della funzione**. I parametri funzionano in modo esattamente uguale alle variabili, con un'unica eccezione: essi **vengono inizializzati dal chiamante della funzione**. I parametri vengono definiti nell'*header* della funzione, mettendoli **tra le parentesi tonde poste dopo l'identificatore** - in presenza di più parametri vengono separati per mezzo di virgole `,`,
```cpp
void stampaCose() { // Funzione con 0 parametri
	std::cout << "Ciao!" << '\n';
}

void stampaValore(int x) { // Funzione con 1 parametro
	std::cout << x << '\n';
}

int somma(int x, int y) { // Funzione con 2 parametri
	return x + y;
}
```
Un ***argument*** è un valore passato **dal chiamante** quando la funzione viene chiamata. 
```cpp
stampaCose(); // Nessun argument
stampaValore(4); // 4 è l'argument passato a stampaValore()
somma(3, 5); // 3 e 5 sono argument passati a somma()
```
Anche in presenza di più argomenti essi vengono separati da virgole `,`.

Quando viene chiamata una funzione, i parametri in essa specificati vengono creati sottoforma di variabili, e il valore di ogni argomento viene copiato nel corrispettivo parametro usando una *[[1.4 ~ Variable assignment and initialization#Copy-initialization|copy-intialization]]*. Questo processo viene detto ***pass by value*** (*passaggio per valore*) e i parametri che utilizzano tale processo vengono detti ***value parameters*** (*parametri*).
```cpp
// Funzioni con due parametri interi x e y
// I valori vengono passati dal chiamante
void printValues(int x, int y) {
	std::cout << x << '\n';
	std::cout << y << '\n';
}

int main() {
	printValues(6, 7); // Chiamata con due argomenti: 6 e 7
	
	return 0;
}
/*
Output:
	6
	7
*/
```

Il numero di argomenti deve *generalmente* essere lo stesso di quello dei parametri. Gli argomenti possono essere **una qualsiasi *[[1.10 ~ Introduction to expressions#Expressions|expression]]***.

Possiamo quindi risolvere il programma scritto prima nel seguente modo:
```cpp
#include <iostream>

int getValueFromUser() {
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;

	return input;
}

// Funziona che stampa il doppio di num
void printDouble(int num) {
	std::cout << num << " doubled is: " << num * 2 << '\n';
}

int main() {
	int num { getValueFromUser() };

	printDouble(num);

	return 0;
}
```

È possibile utilizzare un *[[2.2 ~ Function return values (value-returning functions)#Return values|return value]]* come *argument* per un'altra funzione:
```cpp
#include <iostream>

int sum(int x, int y) { // Somma di due numeri.
	return x + y;
}

int square(int num) { // Quadrato di un numero.
	return num * num;
}

int main() {
	// sum(2, 3) restituirà il valore 5
	// che viene usato come argument per la funzione square().
	int n{ square(sum(2,3)) };
	std::cout << n << '\n';
	
	return 0;
}
// Output: 25
```
In questo ultimo caso abbiamo inoltre utilizzato una combinazione di *return value* e parametri per creare delle funzioni che, inseriti in input dei dati, calcolano dei valori e poi tali valori vengono usati direttamente nella funzione `main()`. Spieghiamo l'esecuzione della riga:
```cpp
int n{ square(sum(2,3)) };
```
- Quando lo *statement* viene valutato, è necessario capire con quale valore inizializzare la variabile `n`. Tale valore è `square(sum(2,3))`, una expression da valutare per ottenere il valore iniziale;
- Di tale expression viene valutata per prima la funzione `square()`, la quale contiene come *argument* l'espressione `sum(2, 3)`, che deve essere valutata per ottenere il valore da assegnare al parametro `num` di `square()`;
- `sum(2, 3)` restituisce `5`, il quale diventa l'*argument* della funzione `square()`. Viene quindi valutata `square(5)` che restituisce `25`. `n` viene quindi inizializzata a `25` e viene infine stampato `25`.
Più semplicemente si passa per queste 3 fasi:
```
n{ square(sum(2,3)) } -> n{ square(5) } -> n{ 25 };
```

### Unreferenced parameters and unnamed parameters
Ci sono alcuni casi in cui delle funzioni avranno dei parametri che *non vengono usati al loro interno*. Queste prendono il nome di ***unreferenced parameters***; un semplice esempio è:
```cpp
void faiQualcosa(int valore) {
	// Qui dentro il parametro valore non viene usato.
}

int main() {
	faiQualcosa(4);
	
	return 0;
}
```
Un *unreferenced parameter* verrà segnalato in fase di compilazione tramite un **warning**, in modo molto simile alle [[1.4 ~ Variable assignment and initialization#Variabili non usate|una variabile non usata]]. 

Nella definizione di una funzione, il nome dei parametri è ***totalmente opzionale***. Nei casi in cui un parametro ha necessità di esistere ma non viene utilizzato all'interno del corpo della funzione si può semplicemente ***ometterne il nome***. Questo *parametro senza nome* viene detto ***unnamed parameter***.
```cpp
// Unnamed parameter: nessun warning!
void faiQualcosa(int) {
	// Qui dentro il parametro non verrà usato.
}
```
Si raccomanda comunque di specificare il nome del parametro attraverso un commento:
```cpp
void faiQualcosa(int /*valore*/) {
}
```

Questa cosa potrebbe non avere molto senso, tuttavia lo assumerà in futuro!

#### Il ***remainder operator*** `operator%` 
Il ***remainder operator*** (chiamato anche ***operatore modulo*** o ***di resto***) è un [[6.2 ~ Arithmetic operators|operatore aritmetico]] che **restituisce il valore del *resto* di una *divisione intera***. Ad esempio, siccome `7 / 4` fa `1` con *resto* `3`,  allora **`7 % 4` restituisce `3`**.

`operator%` funziona **solamente con operandi [[4.4 ~ Signed integers|integers]]**. 

L'utilità di questo operatore sta nel suo uso per verificare ***se un numero è divisibile per un certo valore***. Se infatti `a % b` da come risultato `0`, significa che `b` è **un divisore** di `a`.

Questo programma, inseriti due numeri, verificherà se il secondo è un divisore del primo.
```cpp
#include <iostream>

bool isDivisor(int a, int b) {
	// operator== controlla se il valore dei due operandi è uguale
	return (a % b) == 0; 
}

int main() {
	std::cout << "Inserisci un numero: ";
	int a {};
	std::cin >> a;
	
	std::cout << "Inserisci un altro numero: ";
	int b {};
	std::cin >> b;
	
	if (isDivisor(a, b)) 
		std::cout << b << " è un divisore di " << a << '\n';
	else
		std::cout << b << " non è un divisore di " << a << '\n';
		
	return 0;
}
```

##### Resto con operandi negativi
Il ***remainder operator*** funziona anche per operandi negativi. Il segno del risultato **dipende dal segno dell'operando di sinistra** - dato `x % y` il risultato sarà *negativo* se `x` è negativo mentre sarà positivo se `x` è positivo.

Questa cosa potrebbe causare problemi nel caso avvenga una comparazione tra il resto di una divisione e un numero - in alcuni casi, in cui il resto è negativo, il comportamento di un programma potrebbe risultare errato. È pertanto **consigliabile comparare il resto di divisioni a `0`** in quanto nè negativo nè positivo.

```cpp
bool dispari1(int x) {
	// Se inserisco -5, il resto sarà -1, 
	// quindi mi darà false anche se -5 è dispari!
	return (x % 2) == 1;
}

bool dispari2(int x) {
	// Questo risolve ogni problema!
	return (x % 2) != 0;
}
```

#### Elevamento a potenza
C++ **non include di base un operatore per l'elevamento a potenza**.
All'interno dell'header `<cmath>`, viene fornito il metodo `pow()` che è in grado di effettuare elevamenti a potenza dati come argomenti *una base ed un esponente*.

Questo metodo potrebbe però causare problemi, in quanto sia i parametri (*base ed esponente*) sia **il valore di ritorno** sono di tipo `double` - questo introduce possibili [[4.8 ~ Floating point numbers#*Rounding errors* make floating point comparisons tricky|errori di arrotondamento]] e quindi la funzione potrebbe fornire risultati errati. Pertanto, se si vuole eseguire un elevamento a potenza, è opportuno scrivere un'opportuna funzione che compia questa mansione. 

L'elevamento a potenza intero non è stato incluso come operatore nella *libreria standard* in quanto causa nella maggior parte dei casi [[4.4 ~ Signed integers#Overflow|integer overflow]].

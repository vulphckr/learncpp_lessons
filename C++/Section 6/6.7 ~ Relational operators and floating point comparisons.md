I ***relational operators*** (*operatori relazionali*) sono gli operatori che **permettono di comparare due valori**.
Esistono ***sei*** operatori relazionali:
- `operator>` - maggiore di (*greater than*);
- `operator<` - minore di (*lesser than*);
- `operator>=` - maggiore o uguale (*greater than or equals*);
- `operator<=` - minore o uguale (*lesser than or equals*);
- `operator==` - uguale a (*equality*);
- `operator!=` - diverso da (*inequality*).

L'uso di questi operatori è piuttosto intuitivo - se la condizione richiesta viene rispettata, l'espressione che ne fa uso viene valutata `true`, altrimenti viene valutata `false`.

Esempio con `operator==`:
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci x: ";
	int x {}
	std::cin >> x;
	
	std::cout << "Inserisci y: ";
	int y {};
	std::cin >> y;
	
	if (x == y)
		std::cout << "I due valori inseriti sono uguali.";
	else
		std::cout << "I due valori inseriti sono diversi.";

	return 0;
}
```


#### Valori condizionali booleani
Normalmente, le condizioni presenti negli *[[4.10 ~ Introduction to if statements|if statements]]* e nell'[[6.6 ~ The conditional operator|operatore ternario]] sono di tipo `bool`, ossia che vengono valutate a `true` o `false`.

Molto spesso può essere scritta la condizione in questo modo:
```cpp
if (cond == true) ...
```
tuttavia è scritta in modo ridondante, in quanto `== true` non aggiunge nessun'altro valore da controllare - quindi può essere omessa e il significato rimane lo stesso.
```cpp
if (cond) ...
```

Anche  con i valori `false` è possibile fare lo stesso:
```cpp
if (cond == false) ... // Ridondante
if (!cond) ... // Meglio!
```

#### Comparare valori *floating-point* causa problemi
Supponiamo di avere il seguente codice:
```cpp
#include <iostream>

int main() {
	constexpr double x { 100.00 - 99.99 }; // Matematicamente fa 0.01
	constexpr double y { 1.00 - 0.99 }; // Matematicamente fa 0.01
	
	if (x == y)
		std::cout << "I due numeri sono uguali.\n";
	else
		std::cout << "I due numeri sono diversi.\n";
		
	return 0;
}
```
`x` e `y` hanno lo stesso valore matematico `0.01`, ottenuto in due modi diversi - pertanto matematicamente sono lo stesso numero. Tuttavia, quando eseguiamo il programma l'output mostra `"I due numeri sono diversi"`.

Questo è dovuto agli [[4.8 ~ Floating point numbers#*Rounding errors* make floating point comparisons tricky|errori di arrotondamento]] dovuti al modo in cui i numeri *floating point* sono memorizzati in memoria e alla **propagazione dei loro errori di arrotondamento a causa delle operazioni *floating point***.

La comparazione di numeri *floating point* tramite gli operatori appena descritti ***non è consistente*** - non possiamo usarli per effettuare comparazioni di numeri di questo tipo.

##### Maggiore/Minore tra *floating point*
Gli operatori di comparazione di tipo *minore e maggiore* possono essere usati con i numeri *floating point* **nella maggior parte dei casi**, in particolare quando due numeri sono molto distanti tra loro (in questo caso gli errori di arrotondamento sono trascurabili).

Tuttavia, se **gli operandi sono molto simili tra loro**, il risultato di questa operazione diventa inconsistente a causa dei possibili errori di arrotondamento.

L'uso di questi operatori è possibile se si è consapevoli dei possibili errori che si potrebbero verificare nella comparazione di valori molto vicini tra loro.

##### Uguaglianza tra *floating point*
Gli operatori di uguaglianza/disuguaglianza sono ***molto più problematici*** di quelli di comparazione nel caso dei *floating point*. Questo perchè la restituzione di `true` avviene **se e solo se i valori sono *esattamente identici***.

Gli errori di arrotondamento dei *floating point* fanno in modo che, anche alla più minima differenza tra due valori, **l'uguaglianza non sia rispettata**. `0.3 == 0.2 + 0.1` restituisce `false` a causa di questo.

C'è però ***una singola eccezione*** - è possibile usare gli operatori di uguaglianza/disuguaglianza per la comparazione tra ***literal*** ossia:
- Tra un *literal* e una variabile inizializzata con *un literal dello stesso tipo*;
- Tra un *literal* e una chiamata a funzione che restituisce *un literal dello stesso tipo*.

Infine, non è consigliabile confrontare due numeri *floating point* di tipi diversi. Ad esempio, `9.8 == 9.8f` restituisce `false`.

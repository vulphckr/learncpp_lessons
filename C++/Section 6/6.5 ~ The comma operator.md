Il ***comma operator*** (*operatore virgola*) `operator,` permette **la valutazione di più espressioni** nei casi in cui ***viene richiesta una singola espressione***.

`operator,` **valuta l'operando di sinistra**, poi **valuta l'operando di destra** ed infine ***restituisce il valore dell'operando di destra***.

```cpp
#include <iostream>

int main() {
	int x { 2 };
	int y { 2 };
	
	// incremento x e y, poi restituisco l'operando di destra
	std::cout << (++x, ++y) << '\n';
	return 0;
}
```
Output:
```
3
```

Siccome `operator,` ha il più basso [[6.1 ~ Operator precedence and associativity#Precedenza degli operatori|livello di precedenza]], è molto comune che molto spesso si effettuino errori nel suo uso:
```cpp
z = (a, b); // valuto a, poi valuto b e assegno quest'ultimo valore a z

z = a, b; // valutato come (z = a), b. a viene assegnato a z, b viene valutato poi scartato.
```

Nella quasi totalità dei casi, **ciò che può essere fatto con `operator,` può essere fatto usando due espressioni separate invece che una**. La maggior parte dei programmatori *non usa `operator,`* - tuttavia trova una sua utile applicazione ***nei cicli for***.

> [!tip] Uso di `operator,`
> L'uso di `operator,` è scoraggiato, se non per i ***cicli for***.

#### Virgola come separatore
Abbiamo visto che le virgole, all'interno del linguaggio, vengono usate con **funzione di separazione**.
```cpp
void foo(int x, int y) { // virgola come separatore di parametri
	add(2, 3); // virgola come separatore di argomenti
	
	// virgola come separatore di definizione di variabile (da non fare!)
	int x = 2, y = 3; 
}
```
Queste separazioni ***non fanno uso di `operator,`***.

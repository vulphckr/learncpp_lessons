Fino a qui abbiamo visto tipi di dato che permettono di memorizzare numeri [[4.4 ~ Signed integers|interi]], [[4.8 ~ Floating point numbers|decimali]] oppure [[4.9 ~ Boolean values|vero o falso]]. Vediamo adesso un tipo di dato che è in grado di memorizzare ***lettere e segni di punteggiatura***, ossia i `char`.

#### `char` e caratteri
Il tipo di dato `char` è stato introdotto al fine di memorizzare un **singolo carattere**. Un ***carattere*** può essere una lettera, un numero, un segno di punteggiatura oppure un *[[1.8 ~ Whitespace and basic formatting|whitespace]]*.

Il tipo di dato `char` è un tipo di dato ***integrale***, in modo simile a `bool` o agli *integer*.
Se per esempio, nei `bool`, la memorizzazione di `0` viene interpretata come `false` e qualsiasi valore diverso da `0` viene interpretato come `true`, nei `char` qualsiasi numero memorizzato viene intepretato come un ***carattere ASCII***.

L'ASCII è uno standard di rappresentazione di caratteri, nel quale ciascun carattere dell'alfabeto inglese (più altri caratteri speciali) corrisponde ad un numero tra 0 e 127, chiamato **codice ASCII**. Per esempio, al codice ASCII 97 corrisponde il carattere `'a'`.
È possibile vedere a che carattere corrisponde ogni codice ASCII tramite la [Tabella ASCII](https://www.ascii-code.com/)
I *literal* di carattere vengono posti tra singoli apici (`'a'`, `'1'`,`' '`...)

#### Inizializzazione di `char`
È possibile inizializzare un `char` in due modi: tramite *literal* o tramite *integer*.
```cpp
// inizializzo ch ad 'a'. In memoria, verrà memorizzato come 97 (ossia il codice ASCII corrispondente al carattere 'a').
char ch {'a'};

// inizializzo ch a 97, il codice ASCII corrispondente al carattere 'a'
char ch2 { 97 };
```
Non è preferibile usare il secondo approccio in quanto è molto semplice confondersi tra un *literal* di carattere numerico e un numero.

#### Stampa di `char`
Utilizzare `std::cout` per stampare una variabile di tipo `char` stamperà il contenuto della variabile sottoforma di carattere ASCII.
È possibile inoltre la stampa di *literal*.
```cpp
#include <iostream>

int main() {
	char ch {'a'};
	char ch2 { 98 }; // corrispondente a 'b'
	
	std::cout << ch << '\n';
	std::cout << ch2 << '\n';
	std::cout << 'c' << '\n'; // stampo un literal
	
	return 0;
}
```
Output:
```
a
b
c
```

#### Input di `char`
È possibile inserire caratteri in input, attribuendoli a una variabile di tipo `char` tramite `std::cin`. Si nota che, durante l'inserimento, è possibile immettere **più caratteri**; in questo caso, `std::cin` considererà solamente **il primo carattere inserito** lasciando gli altri all'interno del buffer di cui `std::cin` fa uso, rendendoli quindi disponibili per estrazioni future sempre tramite `std::cin`.
```cpp
#inclue <iostream>

int main() {
	std::cout << "Inserisci un carattere: ";
	
	char x{};
	std::cin >> x;
	std::cout << "Hai inserito: " << x << '\n';

	return 0;
}
```
Output (inserendo `abc`):
```
Inserisci un carattere: abc
Hai inserito: a
```
*nel buffer di `std::cin` è ancora presente `bc`*.

#### Estrazione di *whitespaces*
[[1.5 ~ Introduction to iostream cout, cin, endl#Come funziona l'estrazione per mezzo di `>>`|Come abbiamo visto quando abbiamo introdotto]] `std::cin`, esso ignora l'estrazione di *whitespace* in testa al buffer.
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un carattere: ";
	
	char x{};
	std::cin >> x; // Riempio il buffer
	std::cout << "Hai inserito: " << x << '\n';
	
	// Estraggo ciò che rimane dal buffer oppure lo riempio di nuovo.
	std::cin >> x; 
	std::cout << "Hai inserito: " << x << '\n';

	return 0;
}
```
Output (inserendo `a b`):
```
Inserisci un carattere: a b
Hai inserito: a
Hai inserito: b
```
Come si nota dall'esempio, lo spazio tra `a` e `b` non viene estratto - questo è dovuto alla natura di `std::cin` di rimuovere tutti i *whitespace* in testa al buffer prima di estrarre il valore.

Al fine di estrarre anche i *whitespace* in input, è possibile usare la funzione `std::cin.get()`, la quale permette di estrarre anche i *whitespace* in testa al buffer.
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un carattere: ";
	
	char x{};
	std::cin.get(x); // Riempio il buffer
	std::cout << "Hai inserito: " << x << '\n';
	
	// Estraggo ciò che rimane dal buffer oppure lo riempio di nuovo.
	std::cin.get(x);
	std::cout << "Hai inserito: " << x << '\n';

	return 0;
}
```
Output (inserendo `a b`):
```
Inserisci un carattere: a b
Hai inserito: a
Hai inserito: 
```

#### Grandezza, range e segno di `char`
In C++, `char` viene definito con una grandezza costante di **1 byte**.

Di default, un `char` può essere ***signed o unsigned***.
- Nel caso un `char` venga usato per memorizzare caratteri ASCII, non è necessario specificare un segno. Questo perchè sia *signed* che *unsigned* possono memorizzare valori tra `0` e `127`.
- Nel caso un `char` venga usato per memorizzare interi molto piccoli (sconsigliato se non per ottimizzazioni estreme), è necessario specificare il segno. Nel caso di *unsigned* il range di valori memorizzabili va da `0` a `255`, mentre nel caso *signed* il range va da `-128` a `127`. 

#### Escape sequences
Alcune sequenze di caratteri hanno un significato speciale per C++; queste vengono dette ***escape sequences***. Esse iniziano con il carattere *backslash* `\`, seguite da una lettera o un numero che ne determinano il significato.

La più comune di quelle che abbiamo visto è `'\n'`, la quale viene interpretata come *newline*.
```cpp
#include <iostream>

int main() {
	std::cout << "Test newline!" << '\n'; // \n può essere posto da solo...
	std::cout << "Hello\nworld!\n"; // ...o incorporato in doppi apici!
	
	return 0;
}
```
Output:
```
Test newline!
Hello
world!
```

Un'altra escape sequence comune è `'\t'`, la quale viene interpretata come un *tab* orizzontale.
```cpp
#include <iostream>

int main() {
	std::cout << "Hello\tworld!" << '\n';
	return 0;
}
```
Output:
```
Hello	world!
```

Altri caratteri di escape utili sono:
- `\'` che stampa un singolo apice;
- `\"` che stampa un doppio apice;
- `\\` che stampa un *backslash*.
![[cpp_escape_sequences.png]]

In generale, le *escape sequences* vanno inserite **tra singoli apici** - un'eccezione **è quando si deve fare output, inserendoli tra doppi apici per avere consistenza con le stringhe**.

#### Avoid multicharacter literals
Il compilatore C++ supporta per motivi di retrocompatibilità con C i ***multicharacter literals***, i quali sono *literal* formati da **più caratteri**. L'uso di questi *literal* va ***evitato*** in quanto, se supportati, il loro comportamento **è determinato dal compilatore** e quindi potrebbero fornire comportamenti inattesi.

#### Altri tipi di `char` a grandezza fissa
Abbiamo visto che `char` ha grandezza fissa di 1 byte, per supportare tutti i caratteri ASCII tra 0 e 127; tuttavia esistono altri formati di rappresentazione di caratteri, come ad esempio Unicode, tramite il quale è possibile rappresentare più di 144.000 caratteri di molteplici lingue.

Siccome Unicode deve rappresentare così tanti caratteri, ha necessità di 32 bit per rappresentare un singolo carattere, ma esistono anche delle versioni di Unicode a 8 o 16 bit: è stato necessario creare un nuovi tipi di dato per la memorizzazione di caratteri a 8, 16 e 32 bit - questi sono `char8_t`, `char16_t` e `char32_t`.

L'uso di questi tipi di dato non è necessario se non si vuole implementare Unicode nel programma da realizzare.

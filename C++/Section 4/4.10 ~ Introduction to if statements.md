Supponiamo di andare al mercato, e nostra madre ci dice "se vedi le fragole in sconto, comprale". Questa è una frase **condizionale** - effettueremo l'azione di "comprare le fragole" **solamente se** la condizione "le fragole sono in sconto" è verificata.

I condizionali sono molto comuni nella programmazione, siccome permettono l'esecuzione di codice solo se certe condizioni vengono rispettate. 
#### if statement

In C++, la più semplice forma di condizionale è un ***if statement***. Un **if statement** permette di eseguire una o più righe di codice **solo se una determinata condizione è verificata**. 
Un if statement ha la seguente forma:
```cpp
if (condition) true_statement;
```
spesso scritto, per leggibilità, nel seguente modo:
```cpp
if (condition)
	true_statement;
```
`condition` è una ***condizione***. Una **condizione** è una qualsiasi espressione che, una volta valutata, produce un **valore booleano**.

Se la `condition` di un if statement produce un risultato `true`, allora viene eseguito `true_statement`; se invece produce un risultato `false`, allora `true_statement` viene saltato.

Ecco un esempio:
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un valore: ";
	int x{};
	std::cin >> x;

	if (x == 0)
		std::cout << "Hai inserito zero!" << '\n';
		
	return 0;
}
```
- Viene richiesto l'inserimento di un numero;
- Viene controllato, per mezzo dell'`operator==`, se il numero è uguale a 0.
	`operator==` è l'operatore di **uguaglianza**, un operatore **binario** che restituisce `true` se i due operandi sono **uguali**, `false` altrimenti.
- Se il valore inserito è uguale a `0`, viene stampato `"Hai inserito zero!"`; in qualsiasi altro caso non viene stampato nulla. 
> [!warning] Differenza tra *if statement* e *if block*
> Un *if statement* esegue, in maniera condizionale, ***un solo statement***. Al fine di eseguire ***più statement*** in maniera condizionale, sarà necessario un ***if block***, che vedremo in seguito.

#### if-else
Supponiamo che, nell'esempio di prima, vogliamo stampare, nel momento in cui non viene inserito il valore `0`, la stringa `"Non hai inserito zero!"`. Per farlo, abbiamo bisogno di un altro if statement, questa volta contrario rispetto al precedente:
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un valore: ";
	int x{};
	std::cin >> x;

	if (x == 0)
		std::cout << "Hai inserito zero!" << '\n';
	if (x != 0)
		std::cout << "Non hai inserito zero!" << '\n';
	return 0;
}
```

NB: viene usato `operator!=`, l'operatore **diverso da**, un operatore **binario** che restituisce `true` se i due operandi sono **diversi**, `false` altrimenti.

Il programma risultante è **più complesso di quanto debba essere**. Possiamo infatti usare un'alternativa all'if statement chiamato ***if-else statement***. Esso ha seguente forma:
```cpp
if (condition)
	true_statement;
else
	false_statement
```
Se la `condition` di un if-else statement produce un risultato `true`, allora viene eseguito `true_statement`; se invece produce un risultato `false` viene eseguito `false_statement`.

Possiamo ora scrivere l'esempio appena fatto tramite un *if-else statement*:
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un valore: ";
	int x{};
	std::cin >> x;

	if (x == 0)
		std::cout << "Hai inserito zero!" << '\n';
	else
		std::cout << "Non hai inserito zero!" << '\n';
	return 0;
}
```

#### Chaining if statements
È possibile concatenare gli if statement (o gli if-else statement). Questo è possibile concatenando if-else a altri if-else.
```cpp
#include <iostream>

int main() {
	std::cout << "Inserisci un valore: ";
	int x{};
	std::cin >> x;

	if (x > 0)
		std::cout << "Hai inserito un numero positivo." << '\n';
	else if (x < 0)
		std::cout << "Hai inserito un numero negativo." << '\n';
	else
		std::cout << "Hai inserito zero." << '\n';

	return 0;
}
```

NB: `operator>` e `operator<` sono gli operatori di **maggiore e minore**, entrambi operatori **binari**:
- `operator>` restituisce `true` se il membro a sinistra è maggiore del membro a destra, `false` altrimenti.
- `operator<` restituisce `true` se il membro a destra è maggiore del membro a sinistra, `false` altrimenti.

#### Non-boolean conditionals
Nel caso di if statement o if else statement, abbiamo visto che la `condition` deve essere:
- un valore booleano (`true` o `false`);
- un espressione condizionale;
- una chiamata a funzione che ha tipo di ritorno booleano;
- una variabile booleana.

Ma cosa succede quando la `condition` **non è un valore booleano oppure non è un espressione che viene valutata a un valore booleano**?

In questi casi, il risultato di ciò che è contenuto nella `condition` **viene convertito a un valore booleano**: se il valore ottenuto è **diverso da 0** l'espressione viene valutata `true`, se invece è **uguale a 0** viene valutata `false`. Per esempio:
```cpp
#include <iostream>

int main() {
    int x { 4 };
    if (x)
        std::cout << "Ciao!\n";
    else
        std::cout << "Addio!\n";

    return 0;
}
```
In questo caso, `if (x)` significa **"se `x` non è nullo o non è vuoto"**, quindi il programma restituirà `"Ciao!"`.

#### If-statements and early returns
Un istruzione `return` che non si trova al termine di una funzione (ossia l'ultima istruzione che esegue) viene detta ***early return***. Questa viene detta *early* (traducibile come *prematura*) siccome la funzione restituisce un valore prima che tutte le istruzioni in essa contenute vengano eseguite. 

Un *early return* che non sfrutta i condizionali non è utile:
```cpp
void myFunc() {
	std::cout << "Ciao!" << '\n';
	
	return; // early return - la funzione ritornerà sempre qua
	
	std::cout << "Come va?" << '\n'; // Questo non viene mai eseguito.
}
```
La seconda istruzione di output non verrà mai eseguita, in quanto la funzione ritornerà sempre prima di tale istruzione - possiamo quindi rimuoverla, rendendo di fatto il nostro *early return* non più un *early return*.

Tuttavia, combinare gli *early return* con gli *if statement* o *if-else statement* risulta particolarmente efficace. 
```cpp
#include <iostream>

// funzione per il valore assoluto
int abs(int x) {
    if (x < 0)
        return -x; // early return (solo quando x < 0)

    return x;
}

int main() {
    std::cout << abs(4) << '\n'; // stampa 4 
    std::cout << abs(-3) << '\n'; // stampa 3

    return 0;
}
```
La funzione `abs(int x)` è una corrispondente della funzione matematica valore assoluto.
Il funzionamento avviene per mezzo di un ***early return condizionale***, il quale:
 - Se il valore passato come parametro è negativo, si attiva l'early return, e viene restituito lo stesso valore di segno invertito;
 - Se il valore passato come parametro è positivo, allora la condizione dell'if statement non è verificata, l'early return viene saltato e viene restituito lo stesso identico valore.

Gli early return erano inizialmente considerati una pratica molto sbagliata, tuttavia col tempo e tramite l'uso dei condizionali si sono rivelati un'ottima alternativa per rifattorizzare codice, rendendolo più leggero e leggibile.

In contesti reali, esistono molte domande la cui risposta è **si** o **no**, per esempio "Ti piace la frutta?", oppure "Franco Callegati è un buon prof?".

È possibile esprimere tali domande sottoforma di espressioni che possono essere **vere o false**: "Mi piace la frutta." (vero), "Franco Callegati è un buon prof." (falso).

Queste espressioni che hanno solo due possibili risultati, ***vero o falso***, sono così comuni che la maggior parte dei linguaggi di programmazione includono tipi specifici per operarvi. Questi tipi di dato si chiamano ***boolean*** (booleani).

#### Variabili booleane
Le variabili booleane possono avere solo due possibili valori: `true` o `false`.
Per dichiarare una variabile booleana usiamo la *keyword* `bool`.
```cpp
bool b;
```
Per indicare *vero* o *falso* si utilizzano le keyword `true` e `false`.
```cpp
bool b1 { true };
bool b2 { false };
b1 = false;
bool b3 {}; // value-initialization a false
```
In modo molto simile a come funziona l'operatore unario *meno* `-` per i numeri, utilizzato per cambiarne il segno, l'operatore unario logico *NOT* `!` viene usato per cambiare un valore booleano da `true` a `false` o viceversa.
```cpp
bool bo { !true }; // Inizializzazione a false.
```
In memoria, i valori booleani non vengono salvati tramite le parole `true` o `false`, ma vengono salvati come il valore `1` per `true` e il valore `0` per `false`. In modo simile, quando vengono valutati, essi vengono valutati come *integers*: `true` diventa `1`, `false` diventa `0`. 
Di fatto, siccome i booleani contengono valori *integrali*, sono essi stessi *un tipo integrale*.

#### Stampa di valori booleani
Quando utilizziamo `std::cout` per stampare valori booleani, verranno stampate le loro controparti *integer*: `0` per `false`, `1` per `true`.
```cpp
#include <iostream>

int main() {
    std::cout << true << '\n'; // true evaluates to 1
    std::cout << !true << '\n'; // !true evaluates to 0

    bool b {false};
    std::cout << b << '\n'; // b is false, which evaluates to 0
    std::cout << !b << '\n'; // !b is true, which evaluates to 1
    return 0;
```
Output:
```
1
0
0
1
```

Se invece della controparte *integer* si vuole stampare il valore a parole (`true` o `false`) è necessario stampare in output `std::boolalpha`. Quando questo carattere viene stampato in output, non viene stampato nulla, ma da quel punto in poi le stampe di valori booleane non saranno numeriche, bensì gli effettivi valori `true` o `false` (è possibile tornare all'output normale stampando in output `std::noboolalpha`).

#### Integer to Boolean conversion
Quando si usa una *list-initialization* è possibile utilizzare `0` per inizializzare un booleano a `false` e `1` per inizializzarlo a `true` (procedura che **va però evitata**).
Usare altri interi causerà **errore di compilazione** siccome le [[1.4 ~ Variable assignment and initialization#La list-initialization non permette narrowing|narrowing conversion sono disabilitate]] per la *list-initialization*.

In ogni altro contesto in cui un *integer* deve essere convertito in un booleano, `0` verrà convertito in `false`, mentre qualsiasi altro valore diverso da `0` verrà convertito in `true`.

#### Inputting Boolean values
L'inserimento in input di valori booleani è di default impostato a **valori numerici**. In particolare, `std::cin` interpreta:
- Il valore `0` come `false`;
- Il valore `1` come `true`;
- Qualsiasi altro valore numerico come `true`, entrando in ***failure mode***;
- Qualsiasi valore non numerico come `false`, entrando in ***failure mode***.

In modo simile a come abbiamo fatto per visualizzare l'effettivo valore di un booleano in output invece che la sua controparte intera, al fine di accogliere in input `true` o `false` per un booleano è necessario, prima di effettuare l'input, accogliere in input `std::boolalpha`.
```cpp
#include <iostream>

int main() {
	boool b{};
	std::cout << "Inserisci un valore booleano: ";
	
	std::cin >> std::boolalpha; // Da ora in poi l'input booleano sarà tramite 'true' o 'false'.
	std::cin >> b;
	
	std::cout << std::boolalpha;
	std::cout << "Hai inserito: " << b << '\n';
	
	return 0;
}
```
> [!warning]
> Dopo aver abilitato `std::boolalpha` in input, i valori numerici non saranno più accettati. Saranno accettati solamente i valori `true` e `false` scritti **in minuscolo** e in nessun'altra forma.
> Inoltre, per input e output, `std::boolalpha` va attivato (e disattivato) separatamente.

#### Boolean return values
I valori booleani vengono spesso usati come **valori di ritorno per funzioni** che controllano che certe condizioni siano verificate o meno. Le funzioni che hanno questa tipologia di funzionamento iniziano solitamente con il prefisso `is` (es. `isEqual()`, `isEven()`) oppure `has` (es. `hasIncreased()`, `hasValue()`).

Se una funzione ha tipo di dato booleano, allora dopo l'istruzione deve essere posto:
- `true` oppure `false`;
- Una espressione che viene valutata come `true` o `false`.

Il tipo di dato `void` è il tipo di dato più semplice. Esso significa **assenza di tipo**.
#### Tipi di dato incompleto
Un tipo di dato si dice ***incompleto*** quando è stato **dichiarato ma non definito** e pertanto il compilatore **ne conosce l'esistenza, ma non sa quanta memoria allocare per gli oggetti di quel tipo**.

Variabili di tipi di dato incompleti **non possono essere istanziate**.

`void` è un tipo di dato intenzionalmente ***incompleto***, in quanto non vi è necessità di allocare memoria per un'assenza di tipo.

#### Funzioni che non ritornano un valore
L'uso più comune di `void` è per indicare **funzioni che non hanno valore di ritorno**.
```cpp
#include <iostream>

void helloWorld() { // Tipo di dato void, nessun valore di ritornox.
	std::cout << "Hello, world!" << '\n';
	// non c'è return!
}
```
Se una funzione di tipo `void` restituisce un valore, il compilatore segnalerà la cosa per mezzo di **un errore di compilazione**.

##### Deprecato: `void` per segnalare assenza di parametri
In C `void` viene anche utilizzato per segnalare la mancanza di parametri quando una funzione (o un suo prototipo) viene definito.
```cpp
int getValue(void) { // void qui significa che non ci sono parametri.
	return 67;
}
```
In C++ è possibile fare la stessa cosa, ai fini di retrocompatibilità, ma è considerata una pratica **deprecata**. Se una funzione non accetta parametri, si lasciano vuote le parentesi.

#### Altro uso di `void` 
`void` viene anche utilizzato per i ***void pointers***. Siccome non sappiamo cos'è un puntatore, per ora non ci preoccuperemo di che cosa sono i *void pointe*r.

Abbiamo visto che, quando una variabile viene definita, è possibile anche inizializzarla tramite un valore di inizializzazione. Tale valore, se specificato, verrà **copiato** all'indirizzo di memoria riservato per la variabile. 
```cpp
#include <iostream>

int main() {
	int x { 5 }; // 5 viene copiato all'indirizzo di memoria di x
	std::cout << x << '\n';
	
	return 0;
}
```
Per i [[4.1 ~ Introduction to fundamental data types|tipi di dato fondamentali]], questa copia e allocazione risulta particolarmente rapida. Tuttavia, per tipi di dato composti come `std::string`, [[5.7 ~ Introduction to stdstring#Inizializzare, passare per valore e ritornare una `std string` è costoso|la copia risulta lenta e costosa]].
```cpp
#include <iostream>
#include <string>

int main() {
	// "Hello world!" copiato al'indirizzo di memoria riservato a x.
	std::string x { "Hello world!" }; 
	std::cout << x << '\n';
	
	return 0;
}
```
La copia avviene anche se una `std::string` viene passata *per valore* come parametro a una funzione.
```cpp
#include <iostream>
#include <string>

// il valore dell'argomento passato viene copiato in myStr
void printString(std::string myStr) {
	std::cout << myStr << '\n';
}

int main() {
	// "Hello world!" copiato al'indirizzo di memoria riservato a x.
	std::string x { "Hello world!" }; 
	printString(x);
	
	return 0;
}
```
Questo esempio mostra, in due semplici operazioni, due costosissime copie eseguite su una `std::string`. Sarebbe opportuno semplificare il tutto e rendere il tutto molto più leggero.

### `std::string_view`
A partire da C++17 è stato introdotto un nuovo tipo di dato relativo alle stringhe, `std::string_view`, il quale vive nell'header `<string_view>`. 

`std::string_view` fornisce **un accesso di *sola lettura*** di una stringa già esistente, la quale può essere *una stringa C-Style, una `std::string` o un'altra `std::string_view`*.
Con *sola lettura* si intende che il valore contenuto **può essere letto, ma non modificato**.

Rifacendo l'esempio precedente con l'uso di `std::string_view`:
```cpp
#include <iostream>
#include <string_view> // header per std::string_view

// myStr fornisce un accesso di sola lettura a qualsiasi argomento passato
void printString(std::string_view myStr) {
	std::cout << myStr << '\n';
}

int main() {
	std::string_view x { "Hello world!" }; // ora std::string_view
	printString(x);
	
	return 0;
}
```
Quando inizializziamo `x` con la *stringa C-Style* `"Hello world!"`, essendo `x` di tipo `std::string_view`, la variabile fornirà semplicemente un accesso in sola lettura a ciò che è stato inserito. Questo avviene anche quando una `std::string_view` è il tipo di un *parametro di funzione* - la copia non avviene, in quanto `std::string_view` è semplicemente un tramite per la visualizzazione di una stringa già immessa.

In generale, si preferisce fortemente l'uso di `std::string_view` quando la stringa contenuta all'interno di una variabile **non deve subire modifiche**, e vi si eseguono su essa **operazioni di sola lettura**.

#### Possibili inizializzazioni di `std::string_view`
Una variabile o un parametro di funzione che ha tipo `std::string_view` possono essere inizializzati tramite oggetti avente tipo:
- Un *literal C-Style string*;
- Una variabile di tipo `std::string`;
- Un'altra variabile di tipo `std::string_view`.
```cpp
#include <iostream>
#include <string>
#include <string_view>

void printString(std::string_view myStr) { // Parametro di tipo std::string_view
	std::cout << myStr << '\n';
}

int main() {
	// Inizializzazione di std::string_view tramite C-Style string literal
	std::string_view sv1 { "Hello world!" };
	
	std::string str { "Sono una stringa std::string!" };
	// Inizializzazione di std::string_view tramite std::string
	std::string_view sv2 { str };
	
	// Inizializzazione di std::string_view tramite std::string_view
	std::string_view sv3 { sv2 };
	
	// Argomento di tipo C-Style string literal
	printString("Hello again!");
	// Arogmento di tipo std::string
	printString(str);
	// Argomento di tipo std::string_view
	printString(sv1);
	
	return 0;
}
```

#### Convertire `std::string_view` a  `std::string` non è implicito
Siccome `std::string` ha la necessità di effettuare una copia del valore di inizializzazione, C++ **non permette** la conversione da `std::string_view` ad `std::string` in modo implicito. Tuttavia, è possibile eseguire questa conversione in modo esplicito in due modi:
- Inizializzare una `std::string` con un valore di tipo `std::string_view`;
- Usare `static_cast` (visto [[4.12 ~ Introduction to type conversion and static_cast|qui]]).

#### Assegnamento di valori per `std::string_view`
Quando un nuovo valore viene assegnato (per mezzo di `operator=`) ad una variabile di tipo `std::string_view`, la stringa che visualizzava in precedenza **non verrà alterata**; ciò che succede è che tale variabile smetterà di visualizzare la stringa precedente ed inizierà a visualizzare la nuova stringa che gli viene assegnata. 

È possibile visualizzare ciò tramite questo esempio: 
```cpp
#include <iostream>
#include <string>
#include <string_view>

int main() {
	std::string str { "Ciao!" };
	std::string_view sv { str };
	
	// Stampa "Ciao!"
	std::cout << sv << '\n';
	
	// Assegnazione alla std::string_view. str non verrà modificata
	sv = "Salve!"; 
	
	// Stampano rispettivamente "Salve!" e "Ciao!"
	std::cout << sv << '\n';
	std::cout << str << '\n';
	
	return 0;
}
```
Output:
```
Ciao!
Salve!
Ciao!
```

#### `std::string_view` *literals*
In modo [[5.7 ~ Introduction to stdstring#Literal di `std string`|simile a come visto]] per `std::string`, esistono anche *literal* di tipo `std::string_view`. 

Ricapitolando, se dopo il *string literal*:
- Non viene posto nessun carattere, verrà interpretata come *C-Style string literal*;
- Viene posto il suffisso `s`, verrà interpretata come `std::string`\*:
- Viene posto il suffisso `sv`, verrà interpretata come `std::string_view`\*\*;

(\*) - Se nello scope in cui tale *literal* appare è posta una direttiva `using namespace std::string_literals` 
(\*\*) - Se nello scope in cui tale *literal* appare è posta una direttiva `using namespace std::string_view_literals`

```cpp
#include <iostream>
#include <string>
#include <string_view>

int main() {
    using namespace std::string_literals;
    using namespace std::string_view_literals;

    std::cout << "foo\n";   // Interpretato come C-Style string
    std::cout << "goo\n"s;  // Interpretato come std::string
    std::cout << "moo\n"sv; // Interpretato come std::string_view

    return 0;
}
```

#### `constexpr std::string_view`
A differenza di `std::string`, le `std::string_view` sono perfettamente compatibili con le `constexpr` (viste [[5.6 ~ Constexpr variables|qui]]) e, se specificato, verranno compilate e usate a *compile-time*.
```cpp
#include <iostream>
#include <string_view>

int main() {
	// Valida siccome "Hello world!" è una constant expression
    constexpr std::string_view s{ "Hello, world!" }; 
    
    // s sarà rimpiazzata da "Hello world" a compile-time.
    std::cout << s << '\n';

    return 0;
}
```

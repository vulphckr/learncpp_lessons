Uno ***statement composto*** (*compound statement* spesso chiamato ***block statement***) è un gruppo di ***zero o più [[1.1 ~ Statements and structure of a program|statement]]***, i quali vengono trattati dal compilatore come ***un unico statement***.

I *blocchi* iniziano con `{`, terminano con `}` e contengono gli *statement* da eseguire all'interno delle parentesi. Essi possono essere utilizzati in ***qualsiasi situazione in cui venga richiesto un singolo statement***.
Non è necessario specificare un punto e virgola `;` alla fine del blocco.

Quando [[2.1 ~ Introduction to functions|abbiamo visto le funzioni]] abbiamo già implicitamente introdotto *i blocchi*: infatti **il corpo stesso di una funzione è un blocco**.
```cpp
int add(int x, int y) { // Inizio blocco 
	return x + y;
} // Fine blocco (niente punto e virgola)

int main() { // Inizio blocco
	int val {}; // Inizializzazione, non un blocco.
	add(3, 4);
	
	return 0;
} // Fine blocco
```

#### Blocchi dentro ad altri blocchi
Seppure non è possibile **innestare funzioni dentro funzioni**, ***i blocchi possono essere innestati dentro altri blocchi***.
```cpp
int add(int x, int y) { // Inizio blocco 
	return x + y;
} // Fine blocco (niente punto e virgola)

int main() { // Inizio blocco esterno
	int val {};
	{ // blocco innestato
		add(3, 4);
	} // fine blocco innestato
	return 0;
} // Fine blocco esterno
```
Quando si parla di blocchi innestati, quelli più interni vengono detti ***inner (o nested) blocks*** mentre gli esterni ***outer blocks***.

#### Usare i blocchi per eseguire codice in modo condizionale
Abbiamo introdotto, in una lezione precedente, gli ***[[4.10 ~ Introduction to if statements|if/if else statements]]***, i quali permettono l'esecuzione di *statement* **in maniera condizionale** (ossia se una certa condizione è rispettata).

Uno degli usi più comuni per i blocchi è quello di **utilizzarli in combinazione di *if statements***. Se infatti, al posto di un singolo *statement*, specifichiamo un blocco contenente più *statement*, allora ***tutte le istruzioni contenute nel blocco verranno eseguite***. Questo permette di eseguire **in modo condizionale** più *statement* tramite `if`.
```cpp
#include <iostream>

int main() { // Outer block
	std::cout << "Inserisci un valore: ";
	int val{};
	std::cin >> val;
	
	if (val >= 0) { // Inner block
		std::cout << "Hai inserito un numero positivo.\n";
		std::cout << "Il doppio del valore è " >> 2 * val >> "\n";
	} // Fine inner block
	else { // Inner block
		std::cout << "Hai inserito un numero negativo.\n";
		std::cout << "Il valore inserito, positivo sarebbe " << -val << "\n"; 
	} // Fine inner block
	
	return 0;
} // Fine outer block
```
Se inserisco 5:
```
Inserisci un valore: 5
Hai inserito un numero positivo.
Il doppio del valore è 10
```
Se inserisco -3:
```
Inserisci un valore: -3
Hai inserito un numero negativo.
Il valore inserito, positivo sarebbe 3
```

#### Livello di innestamento dei blocchi
È possibile innestare anche blocchi innestati all'interno di blocchi innestati e così via.
```cpp
#include <iostream>

int main() { // blocco 1, livello di innestamento 1
    std::cout << "Inserisci un numero: ";
    int value {};
    std::cin >> value;

    if (value >  0)
    { // blocco 2, livello di innestamento 2
        if ((value % 2) == 0)
        { // blocco 3, livello di innestamento 3
            std::cout << value << " è positivo e pari\n";
        }
        else
        { // blocco 4, anche questo di livello 3
            std::cout << value << " è positivo e dispari\n";
        }
    }

    return 0;
}
```
Si definisce ***il livello di innestamento*** (***nesting level***) come **il massimo numero possibile di blocchi innestati in cui è possibile trovarsi in ogni momento dentro una funzione** (contano anche i blocchi esterni).
Nell'esempio appena fatto, ci sono 4 blocchi, ma la funzione `main()` **ha livello di innestamento 3**, in quanto non possiamo trovarci più all'interno di 3 blocchi innestati.

Seppur siano supportati (ma non in tutti i casi) fino a 256 livelli di innestamento, è ***buona pratica*** tenere questo valore a **3 o meno**.

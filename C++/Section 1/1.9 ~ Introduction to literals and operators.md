### *Literals*
Abbiamo visto in passato che cos'è un *[[1.3 ~ Introduction to objects and variables#^5e720b|literal]]* - sono valori che vengono inseriti direttamente nel codice sorgente.
```cpp
std::cout << "Hello world!";
int x { 5 };
```
In questo esempio `5` e `"Hello world"` sono *literals*. Per evidenziare meglio la differenza, utilizziamo questo esempio:

```cpp
#include <iostream>

int main() {
	std::cout << 5 << '\n'; // Stampo il literal 5
	
	int x { 5 };
	std::cout << x << '\n'; // Stampo il valore contenuto dentro x
	
	return 0;
}
```
Nella prima stampa, verrà mandato in output `5`, valore *literal* che abbiamo direttamente specificato nel codice sorgente; nella seconda stampa attribuiamo il valore `5`, anch'esso *literal*, alla variabile `x` - anche in questo caso la stampa verrà mandato in output `5`, che è **il valore contenuto all'interno della variabile `x`**. Questo esempio espone come *i literal sono valori costanti* che non possono cambiare durante l'esecuzione *mentre le variabili possono contenere cose diverse in momenti diversi*, siccome il loro spazio di memoria è **manipolabile durante l'esecuzione**.

### *Operators*
In matematica, un'operazione è il processo che presi in input zero o più valori (chiamati ***operandi***) producono come risultato un altro valore (chiamato di *output*). L'operazione specifica viene specificata per mezzo di un simbolo, detto ***operatore***. Un rapido esempio è l'operazione di somma `2 + 3 = 5` - `2` e `3` sono gli *operandi* e `+` è *l'operatore di somma*.

In C++ le operazioni funzionano in modo molto simile alla realtà:
```cpp
#include <iostream>

int main() {
	std::cout << 1 + 2 << '\n';
	
	return 0;
}
```
Questo semplice codice stampa `3`. In questo caso `1` e `2` sono gli ***operandi*** dell'***operatore somma*** `+`, i quali producono il risultato `3`. Il risultato di un'operazione in C++ viene spesso chiamato ***return value***.

Esistono diversi operatori in C++, come quelli aritmetici `+`, `*`, `-`, `/`, `%`. L'assegnamento, `=` è anch'esso un operatore, così come gli operatori di inserimento ed estrazione `<<` e `>>`. Esistono operatori di comparazione, come `==` e anche operatori che sono *keyword*, come `new` e `throw`. È buona norma indicare gli operatori con la dicitura `operator<simbolo>` - ad esempio per indicare l'operatore di somma `+` usiamo `operator+`.

Il numero di *operandi* che assume un *operatore* definisce la sua ***-arity***. Esistono 4 tipologie di *-arity* degli operatori:
- ***Unary operators***: funzionano con un singolo operando. Per esempio, `operator-` è un operatore unario, siccome si occupa di invertire il segno di ciò che gli viene passato in input;
- ***Binary operators***: funzionano con due operandi. Per esempio, `operator+` è un operatore binario, siccome prende i due operandi e ne effettua la somma. Anche `operator<<` e `operator>>` sono operatori binari.
- ***Ternary operators***: funzionano con tre operandi. C'è solo un operatore ternario in C++, il quale è l'operatore condizionale.
- ***Nullary operators***: funzionano senza operandi. C'è un solo operatore nullario in C++, il quale è l'operatore `throw`.
Alcuni operatori possono avere diverse *arity*. `operator-` per esempio, può essere usato sia come operatore binario che come operatore unario.

Gli operatori possono essere concatenati. L'ordine in cui gli operatori vangono applicati ai valori è un argomento di cui parleremo in seguito ed è importante approfondirlo.

#### Side effects
La maggior parte degli operatori produce un ***return value*** ma ci sono anche operatori che non lo fanno. Alcuni operatori hanno comportamenti aggiuntivi - gli operatori che hanno effetti aggiuntivi oltre al produrre un *return value* si dicono che hanno un *side effect*.

Quando parliamo di ***whitespace*** parliamo di caratteri speciali usati per formattare il testo. In C++, ***whitespace indica tre tipologie di caratteri***:
- Lo spazio ` `;
- Il *tab-space*;
- L'andata a capo

### Alcuni elementi vanno separati da un *whitespace*
La sintassi di C++ richiede che alcuni elementi devono essere separati da un *whitespace*. Solitamente due *keyword* o identificatori devono essere separati da *whitespace*:
```cpp
int x; // corretto, int e x sono separati da whitespace
intx; // sbagliato, il compilatore cercherà l'identificatore intx che non è presente nel codice.
```
In certi casi i *newline* sono usati come separatori tra righe. Le ***preprocessor directives*** vanno separate da un *newline*:
```cpp
#import <iostream>
#import <string>
```

### Il testo quotato interpreta letteralmente i *whitespace*
Se il testo è quotato tra doppi apici `""` i *whitespace* presenti al loro interno verranno interpretati in modo letterale. `"Hello World!"` è quindi diverso da `"Hello       world!"`.
Se si hanno due testi quotati tra doppi apici, essi verranno concatenati se sono separati da *whitespace*:
```cpp
std::cout << "Hello " "world!" << '\n';
// Output: Hello world!
```

### Usare *whitespace* per formattare il codice
La formattazione del codice può rendere un codice da illeggibile a facilmente leggibile, permettendo di separare alcune istruzioni da altre. Gli *statement* possono essere separati in righe diverse - questo si fa preferibilmente per *statement* particolarmente lunghi.
```cpp
#include <iostream>
int main() {std::cout << "Hello world!" << '\n'; return 0;
} //Codice formattato male :(
```
```cpp
#include <iostream>

int main() {
	std::cout 
		<< "Hello world!" << '\n';
	
	return 0;
} // Codice ben formattato.
```

Ecco alcune regole generali per una formattazione del testo corretta:
1) Utilizzare *tabspace* e *whitespace* in generale per formattare il testo e renderlo più leggibile;
2) È possibile utilizzare due tipologie di apertura di parentesi graffe: 
```cpp
   int main() {
	   // Così
   }
   
   int main() 
   {
	   // o così
   }
```
3) Ogni *statement* all'interno di parentesi graffe devono stare a un tab di distanza dalla parentesi graffa di apertura;
4) Separare gli statement in più righe se risultano *troppo lunghi* (>80 caratteri);
5) Portare gli operatori di inserimento o estrazione vanno messi all'inizio della nuova riga nel caso di operazioni troppo lunghe;
6) Usare *whitespace* ove necessario per spaziare i commenti.

### Expressions
Consideriamo la seguente serie di statements:
```cpp
int five() { // five() è una funzione che restituisce il valore 5.
	return 5;
}

int main() {
	int a { 2 }; // Variabile a inizializzata a 2
	int b { 2 + 3 }; // Variabile b inizializzata a 5
	int c { (2*3) + 4 }; // Variabile c inizializzata a 10
	int d { b }; // Variabile d inizializzata al valore di b, ossia 5
	int e { five() }; // Variabile e inizializzata al valore dato da five() ossia 5.
}
```
Gli inizializzatori sopra utilizzano diverse tecniche per associare un valore:
- Per `a` viene utilizzato un literal `2`;
- Per `b` e `c` vengono utilizzate delle espressioni aritmetiche;
- Per `d` viene utilizzato il valore contenuto dentro una variabile precedentemente inizializzata, `b`;
- Per `e` viene utilizzato il valore restituito dalla funzione `five()`.
Nella programmazione, le sequenze non vuote di *literal*, variabili, operatori e chiamate a funzioni che calcolano un valore finale prendono il nome di ***expressions*** (espressioni).
Il processo di esecuzione di un'espressione è detto ***evaluation*** (valutazione) e il prodotto di tale espressione è il ***risultato*** o ***return value***.
Prendiamo ora come esempi i seguenti valori:
```cpp
2
"Hello world!"
x
2 + 3
five()
```
- `2`, *literal*, viene valutato come il valore `2`;
- `Hello world!`, *literal*, viene valutato come il valore `Hello world!`;
- `x`, variabile, viene valutata con il valore in essa contenuta;
- `operator+` usa i valori `2` e `3` per ricavare il valore `5`;
- `five()` viene valutata con il valore di ritorno della funzione.
Le espressioni **non terminano con punto e virgola** `;` e *non possono essere compilate da sole* - esse ***fanno parte degli statement***. Per esempio, la sintassi dell'operazione di [[1.4 ~ Variable assignment and initialization#Instantation|instanziazione]] di variabile può essere scritta come:
```
type identifier { expression };
```
- `type` può essere qualsiasi tipo di dato (es. `int`);
- `identifier` è l'identificatore della variabile;
- `expression` è l'espressione utilizzata.

### Expression statements
Alcune espressioni vengono utilizzate principalmente per i loro [[1.9 ~ Introduction to literals and operators#Side effects|side effetcs]] - per esempio, l'espressione `x = 5` viene utilizzata non tanto per valutare il valore effettivo `5`, ma per effettuare un assegnazione. Le espressioni ***non possono essere valutate per se stesse***, ma devono esistere sottoforma di uno *statement*. Chiamiamo ***expression statement*** un'espressione seguita subito dopo da un punto e virgola `;`. Quando un'espressione è usata in un'*expression statement* il suo valore di ritorno viene scartato, ma vengono comunque applicati i suoi *side effect*. Possiamo anche scrivere delle *expression statement* totalmente inutili: basterà utilizzare delle espressioni che non hanno side effect. 

### Subexpressions, full expressions, compound expressions
Si chiama ***subexpression*** una qualsiasi espressione usata come operando. Le *subexpressions* di:
```cpp
x = 4 + 5
```
sono `x` e `4 + 5` e le *subexpression* di `4 + 5` sono `4` e `5`.
Si chiamano ***full expressions*** qualsiasi operazione che **non è una *subexpression***.
Si chiamano infine ***compound expressions*** operazioni che fanno uso di 2 o più operatori. Per esempio `x = 4 + 5` è una *compound expression*.

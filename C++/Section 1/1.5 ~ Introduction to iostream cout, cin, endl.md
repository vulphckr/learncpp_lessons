La **libreria di input/output** è la libreria che fa parte delle librerie standard del linguaggio C++ che si occupa **degli input e gli output di base**. 
Per usare le funzionalità della libreria dobbiamo **includere `iostream` nel nostro codice sorgente** nel seguente modo:
```cpp
#include <iostream>

// Il resto del nostro codice va qua
```
### `std::cout` e `std::endl`
`iostream` contiene delle variabili già pronte all'uso. Una di queste è `std::cout` che ci permette di inviare **dati alla console al fine di stamparli come testo a schermo**. Ricordando il codice del nostro primo programma che stampa `Hello world!` a schermo:
```cpp
#include <iostream> // Per std::cout

int main() {
	std::cout << "Hello world!";
	return 0;
}
```
In questo codice viene utilizzato **l'operatore di inserimento** `<<`, posto tra `std::cout` e il testo che vogliamo inviare alla console. Oltre al testo è possibile stampare sulla console **numeri, caratteri, e il contenuto di variabili**:
```cpp
#include <iostream> // Per std::cout

int main() {
	int x { 5 }; // Variabile x inizializzata a 5
	std::cout << x; // Verrà stampato il contenuto di x, ossia 5
}
// Output: 5
```
È inoltre possibile **concatenare operatori di inserimento `<<` sulla stessa riga** per stampare valori multipli tramite lo stesso `std::cout`.
```cpp
#include <iostream> // Per std::cout

int main() {
	int x { 5 };
	std::cout << x << "Hello" << " world!"; // Multipli << concatenati.
}
// Output: 5Hello world!
```

Avere *statement* di output separati **non significa che tali output risulteranno su righe diverse o spaziati** - compariranno uno sequenzialmente all'altro.
```cpp
#include <iostream> // Per std::cout

int main() {
	std::cout << "Hello";
	std::cout << "world!"; // Due diversi output su due righe diverse.
}
// Output: Helloworld! - Ossia i due testi concatenati!
```
Se vogliamo separare le righe nell'output dobbiamo comunicare alla console di **andare a capo** tramite la stampa di un carattere o una serie di caratteri che segnalano l'andata a capo, detto ***newline***. `iostream` contiene una variabile pronta all'uso, `std::endl`, che produce il ***newline*** quando usata.
```cpp
#include <iostream> // Per std::cout

int main() {
	std::cout << "Hello" << std::endl; // Stampa newline, quindi va a capo
	std::cout << "world!" << std:endl;
}
/*
	Output:
	Hello
	world!
*/
```
*L'ultimo `std::endl` non è necessario, ma sancisce alcune buone pratiche*:
- Ha una funzione simile al punto della sintassi del linguaggio naturale, ossia di sancire quando una frase termina;
- Posiziona il cursore sulla nuova linea, già pronto per output successivi;
- Alcuni sistemi operativi non stampano una nuova linea alla fine dell'esecuzione del programma; ponendo una *newline* alla fine, siamo sicuri di ovviare a questo problema.

`std::cout` è considerato ***buffered***. Gli *statement* presenti all'interno del nostro programma richiedono di inviare in output dei dati ad una certa destinazione - tale output, tuttavia, non viene inviato immediatamente alla destinazione finale, ma viene ***messo in coda*** in una regione di memoria intermedia, detta un ***buffer***. Periodicamente, questo ***buffer viene svuotato*** (***buffer flush***) e i dati collezionati al suo interno vengono trasferiti alla destinazione finale nell'ordine in cui sono arrivati al *buffer*.

### Newline con `\n`
Utilizzare `std::endl` può risultare **inefficiente**, siccome compie due mansioni: inserisce in output una *newline* e ***svuota il buffer***; quest'ultima è un'operazione lenta e se utilizziamo molteplici volte `std::endl` svuoteremo il *buffer* più volte, che è lento e probabilmente non necessario. Inoltre, il sistema di output di C++ svuota il *buffer* automaticamente, quindi non c'è nemmeno bisogno che lo facciamo manualmente.
Per stampare un *newline* senza svuotare il *buffer* possiamo utilizzare il carattere `\n`, posto tra singoli `''` o doppi `""` apici. Il carattere `\n` viene interpretato dal linguaggio come un *newline*, che però non attiva l'azione di svuotare il *buffer* come farebbe `std::endl`, risultando dunque più efficiente.
```cpp
#include <iostream> // Per std::cout

int main() {
	std::cout << "Hello" << '\n'; // Stampa newline, quindi va a capo
	std::cout << "world!" << "\n"; // Non cambia se tra singoli o doppi apici
}
/*
	Output:
	Hello
	world!
*/
```
Convenzionalmente `\n` va messo in singoli apici `''`, anche se è totalmente indifferente usare i doppi apici `""`.
> [!tip] Usare `\n` invece che `std::endl` è preferibile quando si effettuano operazioni di output.

### `std::cin`
Un'altra delle variabili pronte all'uso di `iostream` è `std::cin`. Questa variabile permette di **leggere l'input inserito da tastiera**. Tipicamente ciò che viene inserito come input viene **memorizzato in una variabile** per mezzo dell'***operatore di estrazione*** `>>`, così che esso possa essere utilizzato per le istruzioni rimanenti del programma.
```cpp
#include <iostream>

int main()
{
	// Stampa la richiesta all'utente sul terminale-
    std::cout << "Inserisci un numero: ";
	// In questa variabile sarà contenuto l'input, quindi si usa value-initialization.
    int x{};
     
    std::cin >> x; // Prendi un numero da tastiera e inseriscilo in x.

    std::cout << "Hai inserito " << x << '\n';
    return 0;
}
/*
	Output:
	Inserisci un numero: 5
	Hai inserito: 5
*/
```
Nello stesso modo in cui è possibile inserire in output più dati sulla stessa riga, è possibile inserire più valori in input sulla stessa riga, semplicemente concatenando gli operatori estrazione `>>`.
```cpp
#include <iostream>

int main() {
	int x{};
	int y{};
	cin >> x >> y; // Molteplici inserimenti su stessa riga.
	cout << "Inseriti: " << x << " e " << y << '\n';
	return 0;
}
/*
	Output:
	4 5
	Inseriti: 4 e 5
*/
```
I valori inseriti in questo modo devono essere **separati tramite *whitespace*** (uno spazio, un *tab* o un *newline*).

Abbiamo visto come `std::cout` è ***buffered***, ossia che prima di inviare l'output alla destinazione esso viene "messo in coda" in una zona di memoria detta *buffer* e poi, quando il buffer viene svuotato, viene inviato alla destinazione nell'ordine in cui è arrivato nel *buffer*.
Anche `std::cin` è ***buffered***: 
- I singoli caratteri inseriti in input vengono inseriti **in fondo a un *input buffer*** (in particolare memorizzati in `std::cin`) - anche il carattere di invio, premuto per confermare ciò che si è inserito, viene inserito in coda all'*input buffer* come un carattere `\n`;
- L'operatore di estrazione `>>` rimuove gli eventuali caratteri aggiuntivi (come per esempio `\n`) dall'*input buffer* e converte ciò che è contenuto al suo interno in un valore che viene assegnato **tramite copy-assignment** alla variabile specificata. 
Prendiamo come esempio il seguente programma:
```cpp
#include <iostream>

int main()
{
    std::cout << "Enter two numbers: ";

    int x{};
    std::cin >> x;

    int y{};
    std::cin >> y;

    std::cout << "You entered " << x << " and " << y << '\n';

    return 0;
}
```
Vediamo come funziona l'input buffer tramite due esecuzioni:
- Prima esecuzione: quando incontriamo `std::cin >> x` verrà richiesto il nostro input - premiamo `4` poi *invio*. L'operatore di inserimento assegnerà il valore `4` alla variabile `x`. Quando incontriamo `std::cin >> y` verrà richiesto di nuovo il nostro input - premiamo `5` poi *invio*. L'operatore di inserimento assegnerà il valore `5` alla variabile `y`. L'output risulterà `You entered 4 and 5`;
- Seconda esecuzione: quando incontriamo `std::cin >> x` verrà richiesto il nostro input - digitiamo `4 5` e poi premiamo *invio*. L'operatore di inserimento assegnerà il valore `4` alla variabile `x`. Quando incontriamo `std::cin >> y` ***non verrà richiesto il nostro input*** in quanto ***il buffer non è stato ancora svuotato***. L'operatore di inserimento assegnerà il valore `5`, ancora presente nel buffer, alla variabile `y`. L'output risulterà `You entered 4 and 5`.

#### Come funziona l'estrazione per mezzo di `>>`
L'operatore di inserimento `>>` estrae i valori da inserire nelle variabili nel seguente modo:
1) Se `std::cin` non è in uno stato corretto (per esempio la precedente estrazione è fallita e il buffer contiene ancora elementi), l'estrazione **viene annullata** (e fallirà finché il *buffer* non viene svuotato);
2) I *whitespace* presenti in testa all'*input buffer* vengono scartati. Questa operazione scarterà ogni linea precedentemente inserita nel buffer.
3) Se il buffer è vuoto, l'operatore di inserimento `>>` aspetta che l'utente inserisca altri dati. Ogni *whitespace* in testa al *buffer* viene scartato.
4) L'operatore `>>` **estrae** quanti più caratteri che riesce **consecutivamente**, finché non incontra un *newline* o un carattere non valido per l'estrazione.
Consideriamo il seguente codice:
```cpp
int x{};
std::cin >> x;
```
e consideriamo 3 casistiche:
- Se inseriamo `5b` in input, l'*input buffer* risulterà `5b\n`. Durante l'estrazione, verrà inserito il valore `5` nella variabile `x` e il *buffer* rimarrà con `b\n`;
- Se inseriamo `b` in input, l'input *buffer* risulterà `b\n`. Siccome `b` non è un carattere valido da inserire in un `int`, l'estrazione **fallirà**, in `x` verrà inserito `0` e le estrazioni future falliranno se il buffer non viene svuotato;
- Se `std::cin` non si trova in uno stato corretto, la variabile `x` non verrà modificata ulteriormente, siccome l'estrazione non avverrà.
